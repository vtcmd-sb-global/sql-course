# SQL Course for Beginners

This course covers the basic fundamentals like:

- How to create database using query
- How to create table using query
- How to insert records values in table using query
- How to update a record in a table using query
- How to use <code style="background-color: #f4f4f4; color: #d10057;">WHERE</code> clause and what's its purpose
- How to use <code style="background-color: #f4f4f4; color: #d10057;">GROUP BY</code> clause and what's its purpose
- How to use <code style="background-color: #f4f4f4; color: #d10057;">HAVING</code> clause and what's its purpose
- How to <code style="background-color: #f4f4f4; color: #d10057;">CREATE</code>, <code style="background-color: #f4f4f4; color: #d10057;">ALTER</code> and use <code style="background-color: #f4f4f4; color: #d10057;">STORED PROCEDURES</code> and what it's purpose
- How to <code style="background-color: #f4f4f4; color: #d10057;">CREATE</code>, <code style="background-color: #f4f4f4; color: #d10057;">ALTER</code> and use <code style="background-color: #f4f4f4; color: #d10057;">VIEWS</code> and what it's purpose
- How to <code style="background-color: #f4f4f4; color: #d10057;">CREATE</code>, <code style="background-color: #f4f4f4; color: #d10057;">ALTER</code> and use <code style="background-color: #f4f4f4; color: #d10057;">TRIGGERS</code> and what it's purpose
- What are TRANSACTION and how TRANSACTION lifecycle works and how COMMIT ROLLBACK works in TRANSACTION
