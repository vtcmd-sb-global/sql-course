# SQL Course for Beginners

This course covers the basic fundamentals like:

- How to create database using query
- How to create table using query
- How to insert records values in table using query
- How to update a record in a table using query
- How to use <code>WHERE</code> clause and what's its purpose
- How to use <code>GROUP BY</code> clause and what's its purpose
- How to use <code>HAVING</code> clause and what's its purpose
- How to <code>CREATE</code>, <code>ALTER</code> and use <code>STORED PROCEDURES</code> and what it's purpose
- How to <code>CREATE</code>, <code>ALTER</code> and use <code>VIEWS</code> and what it's purpose
- How to <code>CREATE</code>, <code>ALTER</code> and use <code>TRIGGERS</code> and what it's purpose
- What are TRANSACTION and how TRANSACTION lifecycle works and how COMMIT ROLLBACK works in TRANSACTION
